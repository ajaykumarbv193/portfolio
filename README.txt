AJAY — REEVES-STYLE PORTFOLIO (OPTIMIZED)
=========================================
This is the lightweight GitHub-ready build.

- Reeves-inspired dark portfolio design with blue/white accents
- Original portfolio content and selected images retained
- Pages: Home, Graphic Design, Photography, UI/UX
- Images converted to optimized WebP (transparent artwork remains transparent)
- Removed duplicate images and unused font bundles

Deploy:
1. Extract this ZIP.
2. Upload the contents of this folder to your GitHub repository root.
3. Keep Images, css, font and js folders in their current locations.
4. Enable GitHub Pages from repository Settings > Pages.
